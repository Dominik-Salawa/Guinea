About Guinea

Guinea is a bytecoded-interpreted high-level programming language built with the intention of combining the positives of dynamically-typed languages, and the benefits of statically-typed languages. By making sure our language prioritizes being statically-typed for safety, it also allows for dynamic-typing to ensure you can write code which can support multiple scenarios where needing a variable/list/array to represent a range of unique data-types can be a mess, such as JSONs.


Installation of Guinea

For Linux-based Operating Systems, it depends on your package manager:

  • Arch: pacman, yay | name: guinea
  • Ubuntu/Debian: apt | name: guinea

For Windows, you can install the CLI-pkg for Windows.

What if I want to compile the source-code instead?

To compile the Source-code, you need to use CMake in order for your program to compile correctly.
